# Z.ai CopyCode

Chrome/Edge extension that adds a one-click copy button to code blocks and CodeMirror editors on [z.ai](https://z.ai).

- Real code blocks only (no inline code)
- Works on code editors and `pre` blocks
- No tracking, no network requests

## Install
1. Download or clone this repo
2. Open `chrome://extensions` and enable **Developer mode**
3. Click **Load unpacked** and select this folder
